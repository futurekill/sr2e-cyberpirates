# Shadowrun 2E: Cyberpirates!

Content from *Cyberpirates!* (FASA 7124) for the
[Shadowrun 2nd Edition system](https://github.com/futurekill/sr2e-foundryvtt) on Foundry VTT v13:
Edges & Flaws (in the Shadowrun Companion's format), the Diving and Ship skills, weapons,
diving gear, cyberware, critters, small craft, the African totems (selectable on the Magic tab,
with their spell and conjuring dice), and reference journals: ancestor spirits and Divination, a
page per totem, and the ships, submarines and ship weapons.

Content only: the book's underwater and ship-combat rules are not automated.

## Install
Requires the sr2e system 0.125.1 or later. In Foundry: **Add-on Modules → Install Module**, paste
this manifest URL, then enable the module in your world:

    https://github.com/futurekill/sr2e-cyberpirates/releases/latest/download/module.json

of the book you own.
